# scripts

| Script | Ce face |
|---|---|
| `install.bat` | mediul Python (`.venv`) cu pachetele |
| `start_backend.bat` | baza de date în Docker și backend-ul din cod |
| `start_mobile.bat` | aplicația Flutter în Chrome |
| `seed_users.bat` | conturile demo, parola `123` |
| `run_tests.bat` | testele backend-ului |
| `run_experiments.bat` | comparația strategiilor pe o săptămână |
| `run_evaluation.bat` | evaluarea completă, rezultate în `results/` |
| `run_results.bat [procese]` | regenerează toate rezultatele |
